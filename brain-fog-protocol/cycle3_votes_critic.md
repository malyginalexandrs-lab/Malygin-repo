## Проверка критичных T1–T5 в v3.0_final

| Правка | Учтена корректно? | Где проверено |
|---|---|---|
| T1 (n-of-1) | **Да.** Метрика 1/RT; правило «≥ 1 SD дневных значений, ABAB по 2 недели, в обоих переходах»; мощность пересказана верно (≈ 2% / 75% / 56% / 25%). Один порог эскалации — v2.1 §7.2 п. 7, без дней с триггерами. Пороги 0,5 SD и > 2 SD убраны | §7.2 п. 2, 5, 7; §7.3 |
| T2 (алкоголь) | **Да.** REM — B (39631226), ВСР — C; «3–4 ч» — ⚙; g 0,47–0,66 относятся только к сильному опьянению; AUDIT-C в шлюзе | §1 п. 3, §2 №1 |
| T3 (шлюз ↔ v2.1) | **Да.** Ссылки на v2.1; «2–4 нед → v2.1, 4–6 нед → терапевт»; онемение → «в течение нескольких дней», B12 до первой дозы; PEM с тремя исходами и «скорее всего не PEM» (П-1); PHQ-4, AUDIT-C, STOP-Bang | §1 п. 2–5, 8 |
| T4 (перегрузка) | **Да.** Четыре признака, «2 из 4 за 7 дней», «2 из 3» без устройства, срок 2–3 недели → спортивный врач. Спор о плановой лёгкой неделе вынесен в С3 | §3 стр. 3 |
| T5 (практичность) | **Да.** Уровень 0 (30 с вечером + 5 мин в неделю); эксперимент ≤ 8–10 недель; журнал триггеров по событию; есть недельный план | §7.1, §7.2, §6 |

## Голоса

| № | Голос | Обоснование |
|---|---|---|
| С1 | **А** | Второй порог (> 2 SD) снова рассинхронизировал бы протокол с v2.1. Вне эксперимента тестов нет, так что «устойчивое ухудшение» ловится по самочувствию (2–4 и 4–6 недель) |
| С2 | **А** | Алкоголь — главный рычаг потерь; ВСР ухудшается уже при ≤ 0,25 г/кг. Правило подано как выбор по умолчанию с ⚙, а не как запрет. Кто хочет 1 порцию в будни, может проверить это по ВСР (§7.2 п. 6) |
| С3 | **Б** | Доказательств пользы плановой разгрузки у любителей нет (сам я давал только [ОЗ ⚙]). Плановую лёгкую неделю оставить для ≥ 2 HIIT в неделю, остальным — разгрузка по правилу «2 из 4». Целевой человек обычно попадает в первую группу, так что потерь немного |
| С4 | **А** | Для здоровых всеядных 18–50 есть прямые данные: 35984306, SMD 0,03, I² 0%. В 39070254 эффект сильнее у больных, это смешанная выборка |
| С5 | **А** | Сила триггеров на PVT, вероятно, ниже 0,76 (22025811), поэтому PVT их не обнаружит. ВСР — C, но это единственная метрика, которая на них реагирует. Для остальных вопросов PVT остаётся первичной |
| С6 | **Б** | В варианте А внутреннее противоречие: правило «середина сна ≤ 1 ч» уже допускает подъём +60 мин. Вариант Б соответствует ему, РКИ в пользу строгого варианта нет, а соблюдать Б легче |
| С7 | **А** | Самопроверка уже стоит в №5 («при учёбе»), а польза у неё условная: только при учебной цели. Окно кофеина — правило уровня A, и ЗОЖ-человек его соблюдает не обязательно |

## Протесты
Нет. Критичные правки воплощены корректно; расхождения С3 и С6 решаются голосованием.
