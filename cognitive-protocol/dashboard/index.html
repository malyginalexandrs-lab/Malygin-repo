Рейтинг вмешательств по пользе на минуту усилия

Индекс v3 = польза (0–5) × вес уверенности (A 1,0 · A− 0,9 · B 0,7 · B− 0,6 · C 0,4 · D 0,1) / (1 + log₂(1 + мин/день ÷ 5)). Насыщенность полосы — надёжность доказательств, ◆ — пункт ядра. Баллы пользы — экспертная оценка агентов.
