## Найденные оркестратором недостатки
1. **Индекс П/У игнорирует надёжность доказательств.** Пункты уровня C («уведомления», «без музыки со словами») стоят выше майндфулнеса и природы уровня A. Нужен индекс с весом уверенности.
2. **Индекс ломается при усилии 0 мин.** Нулевые по времени меры получают У = 1–1,5 и завышаются. Нужна согласованная шкала усилия.
3. **Документ 105 КБ** — слишком длинный для применения. Финальная версия должна быть компактной.
4. 78 меток «эвристика». Цикл 3 должен сократить их или явно сгруппировать.
5. Все данные проверены только по абстрактам. Где есть полный текст (PMC), проверить ключевые цифры.
